# 隐私说明

- 城市天气由 Open-Meteo 提供。应用向天气服务发送所选城市的经纬度；非本地索引命中的城市搜索会向地理编码服务发送搜索文字。
- 应用把当前城市、保存城市、偏好标签、衣橱、日程、家庭关注城市和提醒开关写入 OctoSense 为应用分配的私有存储目录。
- 衣橱可选记录存放位置和衣物照片。照片及缩略图保存在应用私有目录，不上传，也不发送给 AI。当前 UI 使用相机拍摄入口，是否可拍摄取决于宿主支持；不提供从磁盘选择照片的入口。
- 首页 AI 出门建议和天气问答会把相关天气、偏好、衣橱、日程及当前问题交给 OctoSense 宿主助手处理。AI 服务商和凭据由宿主配置；应用本身不收集服务商账号或 API 密钥。首次使用需要宿主授权。
- 在“添加衣物”“创建天气偏好”或“添加家庭城市”模式下，当前消息也会交给宿主助手提取对应资料；家庭城市名称会发给 Open-Meteo 地理编码服务用于查找匹配地点。提取或匹配结果会先展示给用户，只有确认后才保存。
- AI 提出的活动安排只显示为待确认草案；用户点击确认后才会保存到应用私有日程表。
- 家庭天气变化检查只在应用打开期间运行；首次观测建立基线，后续符合条件时生成本地提醒。
- 用户可在配套宿主中选择已登录 Rinx 的家人聊天室，开启提醒后，应用将目标聊天室与提醒正文交给 Rinx；发送前由 Rinx 展示完整内容并请求确认。凭据始终由 Rinx 管理，Daycast 不读取 Matrix 密码或令牌。提醒默认关闭，关闭应用后停止检查；真实账号送达尚未验证。
