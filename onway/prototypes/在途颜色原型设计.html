ONWAY / COLOR SYSTEM

在途 · 配色原型设计

Onway · 依据产品需求 V0.1.0 · 功能、场景与数据状态用色

用中性色承载信息，用蓝色指向行动与可信进度，用橙色提示需要注意的变化。场景切换更新同一张卡；颜色不代替状态文字，也不代表数据一定实时。

用色原则场景预览颜色令牌场景映射异常与数据

先确定颜色的职责

01 / 一个场景，一张卡首次准备与无行程用白卡；准备出门到已到达用暗卡。异常作为卡内提示行；方案选择、设置与历史另开页面或面板。

02 / 蓝色保持稳定浅底交互用 #0066CC，暗底链接与可信进度用 #2997FF。步行、公交、地铁不另设整卡颜色；交通方式用图标和线路名区分。

03 / 橙色只表达注意延误、定位受限、失效估计用橙色提示，并说明原因。正常换乘、正常到达、返回起点取消均不使用警告色。

同一张卡，覆盖完整通勤

选择情境查看颜色分工。所有时间、地点与班次均为设计示例；预览不连接真实数据，不记录行程，不发送通知。卡内入口仅示意。

功能与场景用色映射

以下为基于需求的设计建议。暗卡是视觉承载方式，不改变需求中的自动判断、50 米边界与数据可信度规则。

场景 / 功能底色与重点使用规则需求依据
首次准备白卡 · 交互蓝白底黑字；主要操作用交互蓝。设置与方案选择在独立流程中。§3 / A01
无当前行程白卡 · 交互蓝白卡与可读灰表达空态，不用橙色，不伪装正在记录。§4 / A17
准备出门暗卡 · 状态亮蓝暗卡白色主耗时；亮蓝用于状态与入口。没有历史时仅显示规划估计。§4 / A02
出门前延误暗卡 · 状态亮蓝 · 警告提示橙色仅强调增加量与提前建议，主耗时保持白色；无证据不写拥堵。§6.2、§6.4 / A03、A16
前往上车站暗卡 · 状态亮蓝亮蓝标记当前阶段，距离与步行时间可用亮蓝；站名和方向用白色。§4、§5 / A09
候车暗卡 · 状态亮蓝可信来车时间可用亮蓝；同时写明实时、计划或估算与更新时间。§4 / A09、A15
乘车中暗卡 · 状态亮蓝亮蓝实点表示当前确认位置、已确认段用蓝线；未来段用灰色轮廓并标“未到”。§4 / A10、A11
换乘暗卡 · 状态亮蓝维持暗卡与亮蓝，不用警告橙。每次换乘更新线路、方向与上车位置。§7 / A10
下车后步行暗卡 · 状态亮蓝白色显示目的地，亮蓝用于剩余距离与当前进度；尚未到达不显示完成。§4 / A13
已到达暗卡 · 状态亮蓝完成用勾号与文字，无需新增绿色。普通正负差异保持中性色，不将每次慢一点都标橙。§6.1、§10 / A13、A20
到达 · 无历史暗卡 · 状态亮蓝延续到达用色，不显示虚构的差异、均值或个人参考。§6.1 / A01、A20
返回起点取消暗卡 · 状态亮蓝回到准备状态；取消提示用次文字，不用成功绿色或警告橙。§5 / A06
发现更快方案暗卡 · 状态亮蓝卡内亮蓝入口表示可选机会；不用橙色制造紧迫感，未经采用不切换方案。§7 / A04、A05
定位暂不可用暗卡 · 状态亮蓝 · 警告提示保留阶段与确认点；警告橙表达不确定。旧预计用灰色标“上次估计”，停止实时倒计时。§8 / A11、A12、A19
实时班次不可用暗卡 · 状态亮蓝班次缺失默认用次文字，缺失值显示文字而非 0 分钟；影响决策需注意时才用橙色。§8 / A15
后台记录受限暗卡 · 状态亮蓝 · 警告提示警告橙提示能力受限；设置入口亮蓝；手动纠正与补记保持可用。§8 / A07、A17
路线失败 · 有缓存暗卡 · 状态亮蓝 · 警告提示保留缓存路线信息与时间，失效估计灰化并加文字标签；橙色提示影响。§8 / A15
路线失败 · 无缓存白卡 · 交互蓝 · 警告提示白卡浅橙提示区配深琥珀文字；重试用交互蓝。第一版不额外引入错误红。§8 / A01、A15
记录待确认暗卡 · 状态亮蓝 · 警告提示警告橙加“待确认”标签；不展示伪精确总耗时，不误用已到达成功态。§5.2、§8 / A17、A19
通知未授权暗卡 · 状态亮蓝 · 警告提示提前量仍用橙色；权限说明用次文字，不展示“已发送”。正常通勤不每日通知。§6.4、§8 / A16
方案选择 / 地点设置白底黑字 · #0066CC独立页面或面板；选中方案用蓝色描边、勾号与“已选”文字，未选方案为中性色。一个页面只突出当前主要操作。§3、§10 / A01、A05
历史详情 / 返程方案白底黑字 · #0066CC本次柱用蓝色，其他柱可用 #666666，均附数值；浅灰只作轨道。去程与返程分组，返程单独保存方案，不依赖不同颜色区分方向。§2、§6.3、§10

状态叠加与可读性规则

数据性质必须写出来“实时 / 计划 / 估算 / 缓存 / 上次估计”与来源、更新时间一起显示。常规标签用次文字；失效且影响行动时加警告。演示始终标“示例”，不写入真实历史。

异常留在当前卡内优先说明影响当前判断的异常，再显示可采取的操作。定位恢复后按新证据更新；用户纠正优先。场景色不因时钟、习惯窗口或模拟倒计时自行推进。

颜色同时配文字与形状当前站用实点与“已确认”，未来站用轮廓与“未到”，到达用勾号与“已到达”。禁用操作须用真实禁用状态并说明原因；取消本次用明确文案与确认，不靠红色区分。

对比度检查：#0066CC / 白色约 5.57:1；#2997FF / #272729 约 4.94:1；#FF9F0A / #38383A 约 5.69:1；#666666 / #F5F5F7 约 5.27:1；#8A4B00 / #FFF4E5 约 6.26:1。原 #7A7A7A 不用于浅底小字，亮蓝与橙色不配白色小字。#E0E0E0 只作装饰分隔，重要控件边界另用清晰描边。
